Monthlane · iPhone

配置“Monthlane 添加提醒”快捷指令

Monthlane 会把一个 URL 编码的 JSON 交给 Apple 快捷指令。快捷指令循环读取每条提醒，并写入系统提醒事项的 Monthlane 清单。

一、准备清单和快捷指令

  1. 打开 iPhone 的提醒事项，新建清单，名称必须是 Monthlane。
  2. 打开快捷指令，点右上角 +。
  3. 将快捷指令准确命名为 Monthlane 添加提醒。

二、解析 Monthlane 传入的 JSON

  1. 添加动作 Get Dictionary from Input / 从输入中获取词典，输入选择“快捷指令输入”。
  2. 添加 Get Dictionary Value / 获取词典值，键填写 reminders。
  3. 添加 Repeat with Each / 对每项重复，重复对象选择上一步得到的 reminders。
  4. 在循环内部，分别对“重复项目”读取三个词典值：title、triggerAt、notes。
  5. 对 triggerAt 添加 Get Dates from Input / 从输入中获取日期，得到真正的日期时间变量。

三、循环创建系统提醒

  1. 仍在循环内部添加 Add New Reminder / 添加新提醒事项。
  2. 标题选择 title，清单选择 Monthlane，备注选择 notes。
  3. 展开该动作的详细选项，开启日期和时间/提醒，日期时间选择第 5 步解析出的日期变量。不要只把时间写进备注；必须将它设置为提醒事项的实际日期和时间，系统才会到点通知。
  4. 确认“添加新提醒事项”位于“对每项重复”区块内，然后保存快捷指令。

收到的数据格式

{
  "version": 1,
  "list": "Monthlane",
  "timeZone": "Asia/Shanghai",
  "reminders": [
    {
      "title": "港澳通行证到期",
      "triggerAt": "2027-08-02T09:00:00+08:00",
      "notes": "可以申请换发"
    }
  ]
}

四、先做两分钟真机测试

  1. 回到 Monthlane 的事件编辑器，点 Test · 2 minutes。
  2. 允许网页打开快捷指令；首次运行时，允许快捷指令访问提醒事项。
  3. 确认“Monthlane”清单出现 Monthlane test reminder，且有两分钟后的实际日期与时间。
  4. 关闭 Monthlane、锁屏，等待系统通知。若无通知，请在“设置 → 通知 → 提醒事项”开启通知，并检查专注模式。

第一版是单向添加：Monthlane 无法确认快捷指令最终是否写入成功，也不会在编辑事件后更新已经创建的系统提醒。重复点击可能产生重复项，请在提醒事项中手动删除或更新旧记录。
